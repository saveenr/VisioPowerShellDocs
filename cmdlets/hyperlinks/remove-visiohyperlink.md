# Remove-VisioHyperlink



#### Removes the first hyperlink <a href="#removes-the-first-hyperlink" id="removes-the-first-hyperlink"></a>

```
Remove-VisioHyperlink -Index 0
```

#### Removes the third hyperlink <a href="#removes-the-third-hyperlink" id="removes-the-third-hyperlink"></a>

```
Remove-VisioHyperlink -Index 2
```
