# Windows

The **Windows** section covers the on-screen Visio window itself: its zoom level, its position, and its size.

* [`Format-VisioWindow`](window-zoom.md): set zoom (absolute, relative, or zoom-to-target) and / or window rectangle (`-Width`, `-Height`, `-X`, `-Y`).

## On the C# side

These cmdlets wrap the [`client.View`](https://saveenr.gitbook.io/visioautomation/visio-scripting/view) command group on the VisioAutomation gitbook. See [VisioScripting.Client](https://saveenr.gitbook.io/visioautomation/visio-scripting) for the full facade index.
