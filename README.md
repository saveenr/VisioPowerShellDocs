# Introduction

The **Visio PowerShell** module - **VisioPS** - automates and simplifies common tasks for Visio 2010 and later versions. VisioPS **feels natural for PowerShell users** because it maps standard PowerShell verbs and idioms to Visio concepts. &#x20;

VisioPS is open source under the MIT license. Visit the [**VisioAutomation GitHub repo**](https://github.com/saveenr/VisioAutomation).
