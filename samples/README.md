# Samples

Worked examples demonstrating common drawing tasks end-to-end. Each sample is self-contained and can be pasted into a PowerShell session that has the Visio module imported.

* [Draw grid](draw-grid.md): lay out shapes in a grid pattern.
* [Draw fill patterns - slow](draw-fill-patterns.md): render the 40 built-in Visio fill patterns into a labelled grid, one shape at a time. A clear example of a naive shape-by-shape loop.
* [Draw fill patterns - fast](draw-grid-2.md): the same diagram rebuilt to drop many shapes in a single call. Useful as a comparison for performance-sensitive scripts.
* [Countdown days](countdown-days.md): a date-driven sample.
