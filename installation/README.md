# Installation

The **Visio PowerShell** module ships from the [PowerShell Gallery](https://www.powershellgallery.com/packages/Visio/) under the package name `Visio`. Once installed it is available to any PowerShell session via `Import-Module Visio`.

* [Install VisioPS](install-visiops.md) &mdash; installing from the PowerShell Gallery.
* [Uninstall VisioPS](uninstall-visiops.md) &mdash; cleanly removing the module.
* [Detect if VisioPS is installed](detect-visiops.md) &mdash; checking for the module from a script.

A working install also requires Microsoft Visio itself on the same machine &mdash; the module drives Visio via COM and won't function without it.
