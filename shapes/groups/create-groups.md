# Create a group from shapes

#### Group the Selected Shapes <a href="#group-the-selected-shapes" id="group-the-selected-shapes"></a>

```
# NOTE: Select some shapes first
$g = Join-VisioShape
```

#### Group Specific Shapes <a href="#group-specific-shapes" id="group-specific-shapes"></a>

```
$g = Join-VisioShape -Shapes $shape1,$shape2,$shape3
```
